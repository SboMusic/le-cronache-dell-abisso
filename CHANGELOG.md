# Changelog

## 1.0.0 — 2026-10-20

First public release of Le Cronache dell’Abisso / Chronicles of the Abyss.

- Ten missions and a separate final war on eleven maps.
- Human campaign and playable Dark Kin variant using the same maps and main objectives.
- Faction-specific casters, artwork, opposing armies and adapted mission requirements.
- Economy, finite resources, construction, farms, upgrades, research, spells and naval transport.
- Italian/English selection, illustrated menu and campaign briefings.
- Independent campaign slots, autosave/manual save, legacy-save compatibility and corrupt-slot fallback.
- Fullscreen, zoom, minimap and middle-button camera dragging.
- Windows installer, portable package, complete source, licenses and checksums.
- Public developer documentation and Windows build/model-test workflow.

Earlier 0.x builds were local development versions; local historical archives are not published.
