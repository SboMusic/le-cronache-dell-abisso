# Albero originale v1

Generazione integrata ImageGen con sfondo trasparente, senza CLI o API esterna. Output selezionato copiato nel progetto come `art/forest-v1/tree-v1.png` e `warcraft-ii-laboratorio/Application/assets/frontiere-v1/tree-v1.png`; il processo di compilazione lo copia negli asset della demo.

Prompt esatto:

Use case: stylized-concept. Asset type: single tree sprite for an original hand-painted medieval 2D RTS. One complete mature evergreen fir tree, elevated three-quarter view, asymmetrical layered dark forest-green needles with warm sunlight on left, visible brown trunk at base, crisp readable silhouette. Painterly detailed natural foliage matching sandstone and teal-roof village game art. Centered on square canvas with clear margins, entire tree visible, tree fills 85 percent of height. Genuine transparent background, no scenery, no ground patch, no shadow, no snow, no text, no border, no extra trees. Original design.

Il gioco disegna lo stesso albero con leggere variazioni di scala e colore. La crescita dei germogli e la scomparsa all'abbattimento sono gestite dal renderer; lo sprite non contiene fotogrammi di animazione.
